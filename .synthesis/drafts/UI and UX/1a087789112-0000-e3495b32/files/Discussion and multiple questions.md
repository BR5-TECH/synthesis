## Intent

User experience for answering AI questions in discussions should be conceptually aligned with graduation escalations. Discussions should provide a comparable in-panel question-and-answer experience, while remaining a separate discussion feature with its own tool and answer contract. The conversational AI should also be able to ask more than one question at once.

## Specification impact

Graduation escalation behavior remains unchanged. Add a new tool specification and update the discussion UI, `CTA-comment-agent-turns.md`, `AUC-ask-user-comment-tool.md`, conversation-loop, and agent-turn contracts for the pending set, answer submission, batched routing, and history rendering. The batched submission must use one normal routing decision and one fresh later turn per active agent for the complete answer set; individual answer comments must not trigger ordinary per-comment dispatch. Update `CMS-comments-storage.md` if the ordered multi-comment append requires a new atomic or idempotent storage operation. The new tool specification must define the durable pending-set owner and key, serialization, restore, deletion, and crash/idempotency rules. Update `CVP-conversation-presentation.md` because its current session-only presentation rule must remain true for presentation state while allowing the pending question set to persist, and update `AGC-agent-conversations.md` because agent turns and model exchanges remain non-durable even when a pending set is restored. Keep the existing comment record shape and use UI grouping only; do not add a stored pair relation or modify the graduation tool and UI specifications.

## User journey

- User initiates the discussion over the draft via conversational loop.
- AI agent analyzes the draft and compiles a list of questions (one or more).
- AI agent uses a new tool that allows to ask multiple questions at once.
- User sees a special block in the discussion panel, which allows to:
  - Iterate between questions, via pagination mechanism.
  - select exactly one proposed answer variant for each question.
  - optionally enter a note in a dedicated note field for the selected variant.
- Once all questions answered - the results are communicated back to the AI agent.
- Once all question answered - the response is formatted in conversation-like form and rendered in discussion history.
