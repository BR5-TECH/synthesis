# Graduation loop logging

**Spec code:** `GLG`

## Intent
What the loop writes to a run's two persisted log streams, and how every record it writes is attributed. Each turn carries the run's source sink and its structured sink, each record names the phase and the pass it belongs to, redaction happens before persistence rather than after it, and a record is not written until the sink has acknowledged it durably. Out of scope: the streams themselves and their storage, which are `../core/GRS-graduation-run-log-storage.md`'s and `../core/GRD-graduation.md`'s; and the agent-output stream, which is `../core/AGV-agent-activity.md`'s.

## Functional requirements
1. **GLG-FR-QKZV** Every execution turn this loop performs for a run that has a source draft reports its own execution to `../core/GRD-graduation.md` when it ends, carrying the interval it actually ran for and every provider-reported usage record it produced (per `../core/GRD-graduation.md` GRD-FR-NHRY). A turn of a merge run reports nothing for statistics (GLG-FR-HRTD).
2. **GLG-FR-MMVN** The bucket a report carries follows the work it supports: a **work** turn and the clarification judgements taken over its questions report `Authoring`; a **review** turn reports `Reviews`; a **semantic merge** turn of a stream update reports `Reconciliation` (per `../core/DSS-draft-statistics-storage.md` DSS-FR-QLEH). A `merge_work` turn and a `merge_review` turn report no bucket (GLG-FR-HRTD).
3. **GLG-FR-BRKT** This loop **estimates no token value** and reports only what a provider actually reported. Nothing is derived from a task, an instruction, a change set, a character count, a model limit or a price, and a direction the provider did not report is absent rather than zero.
4. **GLG-FR-QKVI** Every turn the loop dispatches carries the run's **two run-scoped log sinks**, and the loop constructs neither: they are handed to it with the run, as its other seams are.
5. **GLG-FR-AVVZ** Each source chunk reaching the source sink carries the **metadata of the turn that produced it** — the run, the phase, the pass, the producer, the agent the turn ran under, the container it was read from, and which of stdout, stderr and executor it came from. The loop supplies the scope; the executor supplies the rest.
6. **GLG-FR-FZHN** Every record the loop appends to the structured sink names the **phase the loop is in** at the moment the fact happens, and a record emitted while the loop moves between phases names the phase being **left**.
7. **GLG-FR-FBKP** A record the loop emits **outside any pass** — while a run waits in its stream's queue, while a semantic merge turn runs at a stream update, or at the tip check, the apply step or the cleanup of a merge run — carries no pass number. A pass number is written only by a record a work or review turn produced, a `merge_work` turn and a `merge_review` turn included.
8. **GLG-FR-YGCI** **Redaction happens before persistence and not after it.** The output the source sink receives has already passed `../tools/EAC-execute-agent-cli.md` EAC-FR-29's masking, and this loop adds no credential, no session identity and no byte of a project file to any record it writes.
9. **GLG-FR-XQTM** **A durable-write acknowledgement is mandatory.** A record handed to either sink is not accounted for until the sink answers that it is durable; a sink that answers with a failure stops the run on the terms `../core/GRD-graduation.md` GRD-FR-IKVE sets.
10. **GLG-FR-RLQZ** A turn that stops without a review appends one `run interrupted` record from the `stage_transition` producer before the run rests. It carries the reason, the process outcome, the duration and the configured limit in milliseconds, and any exit code. Its level is `error` for a failure reason, and `info` for a pause, a shutdown or a project change.
11. **GLG-FR-HRTD** A merge run has no source draft, so the loop writes **no statistic** for it: no `agent_operation` line and no `token_usage` line for a `merge_work` turn, a `merge_review` turn or a clarification judgement over their questions, and no bucket is chosen for them. The turns still write both run-scoped log streams on the terms of GLG-FR-QKVI, GLG-FR-AVVZ and GLG-FR-FZHN, with `phase_id` and `pass` as `../core/GRS-graduation-run-log-storage.md` GRS-FR-HBQT sets them: a `merge_work` turn is attributed as a work turn and a `merge_review` turn as a review turn.
12. **GLG-FR-QNLC** For a merge run the loop emits through `../core/LGC-logging.md`'s internal API, correlated by the run id, one record at each of these boundaries: the dispatch of each `merge_work` and `merge_review` turn, the **tip check** before a dispatch, a Continue or an answer, and at the apply step, with the outcome `ok` or `merge_branch_moved`; the apply step, with the outcome `applied`, `merge_dirty_side`, `merge_guard_held` or `merge_apply_failed`; and the cleanup of the run's merge worktree, scratch branch and snapshot ref, with the outcome `reclaimed` or `reclaim_failed`. A refused tip check is a record of level `WARN`, and a failed apply or a failed cleanup is a record of level `ERROR`. These records carry the domains `ai` and `backend` together (per `GRL-graduation-loop.md` GRL-FR-UVJP), except the cleanup record, which carries `backend` alone.
13. **GLG-FR-WYSP** The records of GLG-FR-QNLC carry the run id, the outcome, the pass number where the boundary lies inside a pass, counts of paths, and object ids of the pinned tips. They carry no file content, no conflict marker text, no finding text, no prompt, no credential and no session identity. The pre-conflict check and the handoff of a merge are not records of the loop: they belong to `../core/WKS-work-streams.md`.

## Contract surface

This spec adds no operation of its own. It settles what the loop writes into the two run-scoped log sinks `../core/GRD-graduation.md` gives every turn, and how each record is attributed to a phase and a pass.

## Non-functional requirements
- Every record is bounded by the run it belongs to, and no record of one run reaches another's stream.
- Writing a record costs the turn that produced it nothing it must wait for beyond the sink's own acknowledgement.
